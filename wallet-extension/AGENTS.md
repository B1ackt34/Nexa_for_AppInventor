# Documentation maintenance

Keep `APP-INVENTOR-GUIDE.md` (Italian) and `APP-INVENTOR-GUIDE.en.md` (English)
in sync whenever development changes public blocks, signatures, events,
properties, behavior, error handling, supported versions or documented limits.
Update both guides in the same change; preserve API identifiers unchanged in
translation. Describe implemented behavior rather than planned features.

Keep manual user-reported validation separate from automated test results.
Do not turn a testnet result into a claim of general safety or mainnet support.
For documentation-only changes, verify block coverage and links; no new AIX
build is required. Never modify published artifacts merely to update a guide.
